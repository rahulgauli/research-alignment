What it's actually made of

Every piece above maps to something you can install

The mock is hand-built HTML so it stays one file, but nothing in it is invented. Each element is the anatomy of a real primitive — same parts, same states, same accessibility contract — so porting it to React is transcription, not redesign.

Tabs @base-ui/react/tabs → shadcn/ui tabs Roving focus, arrow-key navigation, one selected tab per list. The underline is styling; the behavior is the primitive's.
Findings table @tanstack/react-table + shadcn/ui data-table Sorting, column sizing and row selection live in TanStack; shadcn supplies the markup shell. The 3px severity stripe is the only custom cell.
Buttons shadcn/ui button + CVA variants Three variants, two sizes, one disabled state — the whole surface area most apps ever need.
Fields @base-ui/react/field, /select, /switch Base UI's Field wires label, description and error to the control, so validation copy is announced instead of just shown.
Status pills shadcn/ui badge + reserved status tokens Four reserved states, never reused as chart series colors, and each ships with a word — colour alone never carries the meaning.
Passing Minor Serious Critical
Command palette cmdk → shadcn/ui command ⌘K over runs, rubrics and transcripts. In a research tool this is the primary navigation, not a shortcut.
Inspector @base-ui/react/dialog, rendered inline Same component as the modal, with the backdrop off and the position pinned — focus trapping and escape handling come along for free.
Charts Hand-rolled SVG (or Recharts / visx) One series per plot, one hue, a recessive grid, a crosshair on hover, and a tolerance band that means something. No second y-axis, ever.
Icons & motion lucide-react + motion (ex framer-motion) 1.3px strokes at 15px so icons sit at text weight. Motion is reserved for state changes that need explaining.
The token layer

A palette chosen for the subject, not inherited from a starter

Where to go deeper

The reading list behind this page

Grouped by the job each one does: what you build on, what you steal taste from, what makes Claude produce this instead of a generic starter skin, and the craft references worth reading end to end.

Build on

  • Base UIThe MUI team's headless primitives. shadcn/ui's default since July 2026.
  • shadcn/uiCopy-in components you own. The registry, not the look, is the value.
  • Radix PrimitivesStill fully supported by shadcn; init with -b radix.
  • Radix Colors12-step scales built for both themes. Copy the structure even if not the hues.
  • React AriaAdobe's behavior layer — the strictest accessibility contract of the three.
  • Ark UISame idea, framework-agnostic: React, Vue, Solid, Svelte.

Steal taste from

  • Vercel GeistThe reference for restrained, dense, developer-facing product UI.
  • IBM CarbonBest public example of a data-heavy enterprise system, fully documented.
  • Atlassian Design SystemUnmatched writing on content design and empty states.
  • Shopify PolarisRead it for the decision rationale, not the components.
  • GitHub PrimerHow a system survives twenty years of accreted product surface.
  • Material 3 Expressive · Apple HIGThe two poles of 2026: expressive motion vs. Liquid Glass depth.
  • Design Systems Repo · The Component GalleryCompare how thirty systems each solved the same component.

Claude ecosystem

  • frontend-designAnthropic's official skill. Forces a committed aesthetic direction instead of a safe default.
  • web-artifacts-builder · canvas-designSingle-file web apps, and multi-artboard visual layouts.
  • theme-factory · brand-guidelinesGenerate a token set, then hold every screen to it.
  • webapp-testingDrives the built UI in a real browser — the loop that catches visual bugs.
  • Claude DesignAnthropic Labs' visual canvas: iterate on layout, export HTML or hand off to Claude Code.
  • shadcn MCPLets the agent read your registry and install real components instead of guessing markup.
  • Figma Dev Mode MCPHands the agent your variables, components and layout data from the file itself.
  • Chrome DevTools MCP · Playwright MCPGive Claude eyes: it renders the page, then fixes what it sees.

Craft references

  • WAI-ARIA Authoring PracticesThe spec every primitive above is implementing. Read the patterns you use.
  • Inclusive ComponentsHeydon Pickering builds each component from the accessibility outward.
  • Refactoring UIStill the fastest path from "looks amateur" to "looks intentional".
  • tweakcnVisual editor for shadcn themes — good for escaping the default zinc skin.
  • MotionSpring physics and layout animation, with the docs to know when not to.
  • Google Fonts KnowledgeType pairing and scale, written by people who set type for a living.
