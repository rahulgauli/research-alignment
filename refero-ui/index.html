Foundations

Color

The neutral ramp is blue-biased rather than grey — that cool cast is what makes the surface read as expensive instead of flat. Both a solid scale and an alpha scale exist; alphas are used for hairlines, overlays and secondary text so they compose over any background. The accent is monochrome: pure black in light, pure white in dark. Hue is reserved for status.

Foundations

Typography

Instrument Sans carries the interface, Instrument Serif carries display type. Tracking is negative everywhere and tightens as type grows — -0.02em is the baseline, display steps run to -0.03em. Set at zero, the whole system stops looking like itself.
